# Architecture Decision Records

An ADR records a decision, the context that led to it, and the consequences.
Each ADR is a short, immutable document. New decisions create new ADRs.

## Template

```markdown
# ADR-00XX: <Title>

## Status

Proposed | Accepted | Deprecated | Superseded by ADR-00YY

## Context

<problem / forces / constraints>

## Decision

<what was decided>

## Consequences

<positive and negative outcomes>
```
